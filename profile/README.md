# FullMeta

FullMeta is a workspace for application documents and simulation tools.

## Repositories

- [FullMeta](https://github.com/gbaswfm2021/FullMeta) — public FullMeta workspace and distribution.
- [FEM](https://github.com/gbaswfm2021/fem) — finite-element modelling application.
- [Raytracing](https://github.com/gbaswfm2021/raytracing) — raytracing application.

The platform source is private. These links point to repositories maintained separately under the existing GitHub account.
